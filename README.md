# RideWise downloads

The download page and releases of **RideWise**, an Android app for your bike
or car: fuel and how far it goes, service, documents and inspections.

**Download:** https://mhuzaifaibs.github.io/ridewise-downloads/

This repository holds only what people download: the page (`index.html`),
`latest.json` (the newest version, which the app also reads to offer
**Update now**), and the app files under
[Releases](https://github.com/mhuzaifaibs/ridewise-downloads/releases). The
app's source code is private.

Map data shown in the app: towns from GeoNames (CC BY 4.0); areas
© OpenStreetMap contributors (ODbL).
